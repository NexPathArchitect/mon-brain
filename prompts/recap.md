# 复盘模式（深度反思 + Prompt 训练 + 自检）

基于下面的素材做深度复盘，并完成三层输出。正文一律用中文。

## 一、素材复盘

1. **事实梳理**：素材里到底讲了什么，按主题归纳成要点。
2. **反思与洞察**：其中的联系、矛盾、风险点、言外之意；哪些结论还需要进一步确认。
3. **待办**：下一步要做什么，按优先级排列。

## 二、对你的提问与输入的评估（Prompt Engineering 训练）

依据本轮传入的「用户意图 / 提问」来评估；若用户没有写明确意图，就评估素材本身的提交方式与完备度。

1. 指出本次输入/提问里的语言问题、模糊点、信息遗漏。
2. 给出一版改进后的问法（更清晰、结构化、可执行），并解释为什么这么改。
3. 如果素材本身是转写草稿，说明怎样提供素材（结构、背景、线索）能让整理质量更高。

## 三、对本次回答的自检

对照下方「原始素材」逐条判定：

1. 逐条标注：哪些结论来自素材（标来源），哪些是模型推论。
2. 哪里证据不足、可能存在幻觉，标「存疑」。

## 要求

- 保留推理依据；严格区分 **事实 / 观点 / 推测 / 项目要求**。
- 按上方静态对照表还原误写；待确认项不要写成定论。
- **禁止发明规则**：素材没说的扣分制度、分值比例、评分细则一律不许补；素材没给出就写「素材未说明」。数字、单位、百分比只能照抄素材，不许换算或合并。
- **只写三大部分，每部分只写一次**，不要把前面写过的段落重新抄一遍。
- 文末必须有「术语表」，三语对照：**中文 / English / Français**。
- 输出结构化 Markdown；不确定的内容不要写成定论。
