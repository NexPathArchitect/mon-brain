# 整理模式

把下面的原始素材整理成一份结构化的 Markdown 笔记。

## 输出要求

1. 正文一律用中文撰写；只依据素材，不补充素材里没有的内容；拿不准的地方标「存疑」，不要猜成定论。
2. 按主题分组提炼要点；术语第一次出现时给一句大白话解释。
3. 区分四类信息，不要混写：**素材事实** / **他人观点** / **你的推测** / **项目要求**。
4. 按上方「已知转写误差」静态对照表还原误写（人名、术语、命令、型号等）；表中标「待确认」的不要写成定论。
5. 文末列出：复习待办；如有可复用结构（命令、路由、配置、代码骨架），一并列出。
6. 文末必须有「术语表」，三语对照：**中文 / English / Français**；素材里出现的关键术语都要收进去。
7. 输出纯 Markdown，标题层级清晰；不要写寒暄或与素材无关的内容。
